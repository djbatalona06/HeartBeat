# Code of Conduct

HeartBeat is a personal, non-commercial project — a gift between two people,
published openly (see [NOTICE.md](NOTICE.md)). It isn't run by a company or a
community team. If you open an issue, a PR, or a discussion here, this is the
one page of ground rules.

## The standard

Be respectful. Disagree about the code, not about the person. No harassment,
hate speech, personal attacks, or unwelcome contact of any kind — here or
anywhere it might spill over from here (email, other platforms, etc.).

Keep it about the code. This repo's issues and PRs are for bugs, features, and
questions about HeartBeat itself.

## Where this applies

Anywhere this project has a presence on GitHub: issues, pull requests,
discussions, commit messages, and code review.

## Reporting a concern

Email **batalona06@gmail.com**. There's no committee behind this — a report
gets a real read and a real response from the person who maintains the repo.

## Enforcement

There's no tiered process here. Comments that break the standard above get
hidden or locked, and repeat behavior gets the person blocked from the repo.
Maintainer's call, made in good faith.
